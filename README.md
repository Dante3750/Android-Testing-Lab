# Android Testing Lab: TDD & Advanced Mocking

[![Testing](https://img.shields.io/badge/Testing-JUnit--5-brightgreen.svg)](https://junit.org/junit5/)
[![Library](https://img.shields.io/badge/Mocking-MockK-blue.svg)](https://mockk.io/)

A specialized repository dedicated to demonstrating advanced unit testing techniques and the **TDD (Test-Driven Development)** workflow in Android.

---

## 💥 Advanced Mocking with MockK
- Mocking final classes and static methods.
- Stubbing behaviors for complex Use Cases.
- Verifying function calls and parameter capture.


## 🏗 Test Doubles Patterns
- **Stubs**: Hardcoded responses for simplification.
- **Mocks**: Verifying interactions between components.
- **Fakes**: Lightweight in-memory implementations.
